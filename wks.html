Week 2 WKS Reflection

Creating and Hosting a Website

This was my first time making a website and writing code, so I wasn’t sure where to start. Following Dr Holly step by step really helped, I could try each change and see what it did. I learned how to publish a site through GitHub Pages or CampusPress, and was happy to see my own page online. It’s still a simple draft, but making changes feels less intimidating now.

What we learned

Create an index.html file with a title, headings and paragraphs.
link a stylesheet to change colours, fonts and spacing.
build pages using themes and a content management system.
upload website files to a repository and publish them online.

Week 3 WKS Reflection

In this workshop, I used a downloaded scraping tool to collect data from BBC iPlayer. The AI scraper sometimes got things wrong, so I had to try again and check what it produced. I learned that getting a CSV file is only the start: my export included blank cells and button text such as “View all”, which would need cleaning before analysis.

I collected programme listings rather than personal details, but the task still made me think about copyright, respecting the website’s rules and avoiding too many requests.
