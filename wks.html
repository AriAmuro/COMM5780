WKS Reflection

Week 2 · Creating and Hosting a Website

This was my first time building a website and working with code. At first, HTML tags and file names felt unfamiliar. The teacher’s step-by-step guidance made the process much easier to follow. Creating an index.html file in VS Code and adding a title, headings and paragraphs helped me understand how a page is structured.

I also learned that HTML organises content, while CSS controls how it looks. Linking a separate stylesheet showed me how small changes to colours and spacing can change a page. Exploring CampusPress introduced me to a different way of building a website, using themes rather than writing everything myself.

By the end, I had learned how to upload my files and publish my website through GitHub Pages. Seeing my page online made the process feel more achievable. My portfolio is still a draft, but I now feel more confident about editing it. Next, I want to practise adding images and links while keeping the layout simple.
